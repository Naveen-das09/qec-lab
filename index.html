Methods & documentation
One clearly defined experiment
Stim generates a rotated surface-code Z-memory circuit. Each point uses the configured code distance, fixed syndrome rounds, and independent Pauli noise channels. PyMatching predicts logical observable flips from detector samples.
What the chart measures
The logical error probability is the fraction of sampled memory experiments whose predicted logical parity differs from the sampled observable. The x-axis is the channel parameter p, not a measured device-wide error rate.
Uncertainty and stopping
Each point has a fixed shot target and a nominal 95% Wilson interval. Live and budget-truncated results are provisional. Intervals are pointwise, not simultaneous or sequentially valid. Zero failures does not imply perfect protection. Triangles on log plots indicate the interval's upper limit when no failures were observed.
Reproducibility
Exports include simulation circuits, decoder error models, every batch seed and sample size, dependency versions, CSV results, and a replay script. Exact samples also depend on Stim version and CPU SIMD architecture.
Current boundaries
The assistant can inspect results and propose experiments. It cannot run arbitrary code, search papers, operate hardware, or autonomously launch jobs. Detector views do not expose the exact injected error history. This release has one local workspace.
